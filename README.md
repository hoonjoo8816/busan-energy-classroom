# 2050 부산 에너지 정책 연구실

고등학교 1학년 통합과학2 CBL 수업을 위한 블로그형 활동 사이트입니다.

## 현재 구현 범위
- 1차시: 부산 에너지 정책과 문제 인식
- 2차시: 4대 전략·15대 과제 탐구
- 3차시: 제공 자료 분석과 AI 답변 검토
- 4차시: 총예산 100%의 A·B 정책 예산안 구성
- 5차시: 시뮬레이션 비교 및 해석
- 6~10차시: 후속 개발 예정

## 사용 방법
저장소를 내려받아 `index.html`을 브라우저에서 열면 됩니다. 별도의 설치나 빌드가 필요하지 않습니다.

학생 답변은 사용 중인 브라우저에 저장됩니다. 서버로 제출되거나 다른 기기와 자동 동기화되지 않습니다. 차시별 HTML 내려받기와 활동 기록 불러오기 기능이 포함되어 있습니다. 브라우저 환경에 따라 내려받기 동작을 확인한 뒤 수업에 사용하세요.

## 시뮬레이션의 범위
태양광 설치와 고효율 조명 교체에 대한 교육용 가상 모델입니다. 비용·설치 한도·효과 계수는 실제 부산시 사업비나 예측치가 아닙니다. 다른 정책은 실행 조건과 근거를 검토합니다. 발전량과 절감량을 구분하고, 자동으로 최적 정책을 판정하지 않습니다.

자료 출처는 각 수업 페이지에 안내되어 있습니다. 2019년 발표된 정책의 목표와 현재의 달성 실적을 구분하여 읽어야 합니다.

## 공유 범위
수업 사이트 파일만 포함하며, 학생 응답이나 계정 인증 정보는 포함하지 않습니다.
