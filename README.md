# 2050 부산 에너지 정책 연구실

고등학교 1학년 통합과학2 CBL 수업을 위한 블로그형 활동 사이트입니다.

## 현재 구현 범위
- 1차시: 부산 에너지 정책과 문제 인식
- 2차시: 4대 전략·15대 과제 탐구
- 3차시: 제공 자료 분석과 AI 답변 검토
- 4차시: 총예산 100%의 A·B 정책 예산안 구성
- 5차시: 시뮬레이션 비교 및 해석
- 6차시: 1쪽 정책 제안서 자동 완성(이미지·PDF 저장), 발표 듣고 기록, 패들렛 동료 평가, 받은 피드백 정리
- 7차시: 상황 대응 게임 1~2라운드(예비비 설정, 전략별 사건·대응 카드, 도시 장면·상태창, 이유 기록 후 확정, 중간 정리)
- 8차시: 상황 대응 게임 3~5라운드(예산 삭감·전략별 후속 문제·국비 매칭)와 엔딩(유형·배지·원인 분석), 결과 분석
- 9차시: 수정과 재검증(8차시와 같은 사건을 다시 실행, 출발 예비비·계획 예산·한 라운드 선택 중 하나만 바꾸기, 가설 작성 후 실행, 원래 결과와 비교 그래프·라운드별 표, 최대 5회 실험, 최종 수정안)
- 10차시: 최종 정책 제안서(6차시 제안서·9차시 결과 가져오기, 처음 계획 대비 최종 예산·예비비, 최종안 자동 점검, 이미지·PDF 저장, 패들렛 공유 댓글 틀), 구성원별 개인 성찰(배운 점·AI 활용 판단·역할 기여), CBL 마무리
- 자료실(`#library`): 15대 과제별 검증 방법 안내표, 4대 전략별 교사 제공 데이터 꾸러미(그래프·표·탐구 질문)

## 사용 방법
저장소를 내려받아 `index.html`을 브라우저에서 열면 됩니다. 별도의 설치나 빌드가 필요하지 않습니다.

학생 답변은 사용 중인 브라우저에 저장됩니다. 서버로 제출되거나 다른 기기와 자동 동기화되지 않습니다. 차시별 HTML 내려받기와 활동 기록 불러오기 기능이 포함되어 있습니다. 브라우저 환경에 따라 내려받기 동작을 확인한 뒤 수업에 사용하세요.

## 시뮬레이션의 범위
태양광 설치와 고효율 조명 교체에 대한 교육용 가상 모델입니다. 비용·설치 한도·효과 계수는 실제 부산시 사업비나 예측치가 아닙니다. 다른 정책은 실행 조건과 근거를 검토합니다. 발전량과 절감량을 구분하고, 자동으로 최적 정책을 판정하지 않습니다.

자료 출처는 각 수업 페이지에 안내되어 있습니다. 2019년 발표된 정책의 목표와 현재의 달성 실적을 구분하여 읽어야 합니다.

## 공유 범위
수업 사이트 파일만 포함하며, 학생 응답이나 계정 인증 정보는 포함하지 않습니다.

## 자료실과 교사 제공 데이터
- 사이트의 **자료실** 메뉴에서 15대 과제별 검증 방법(수치 계산·자료 확인·근거 서술)과 전략별 데이터 꾸러미를 볼 수 있습니다.
- 같은 자료를 엑셀 파일 `data/busan-energy-teacher-data.xlsx`로 내려받을 수 있습니다. 파란 숫자는 원자료 값, 검은 숫자는 수식 계산값입니다.
- 자료 수집일: 2026년 10월 27일. 공공데이터포털, 부산광역시 누리집, 언론 보도를 출처로 하며 각 자료에 기준 시점과 링크를 표시했습니다.

## 6차시 패들렛 연결 (교사용)
1. 패들렛에서 보드를 만들고 게시물 설정에서 **댓글**을 켜고, **반응(리액션)을 별점**으로 설정합니다. 필요하면 게시물·댓글 승인 후 공개를 켭니다.
2. `index.html`에서 `const PADLET_URL='';`을 찾아 따옴표 안에 보드 주소를 넣고 다시 업로드하면, 6차시에 ‘학급 패들렛 열기’ 버튼이 나타납니다. 비워 두면 “선생님이 안내합니다”로 표시됩니다.
3. 학생은 제안서를 이미지(PNG)나 PDF로 저장해 게시물로 올리고, 다른 모둠 게시물에 별점(1~5점)과 ‘평가 댓글 틀’(근거·실행 가능성·한계 인식 각 1~5점, 좋은 점·질문·제안)을 남깁니다.

## 9~10차시 운영 메모 (교사용)
- 9차시는 8차시 게임을 엔딩까지 마친 기록이 필요합니다. 다른 기기라면 8차시 HTML을 ‘기록 불러오기’로 불러온 뒤 9차시로 이동합니다. 9차시 HTML에는 8차시 결과가 함께 저장됩니다.
- 재검증은 무작위가 아니라 같은 사건을 같은 순서로 다시 계산합니다. 바꾼 것 때문에 뒤 라운드의 원래 선택을 할 수 없으면(예비비 부족 등) 비용 없는 선택으로 자동 대체하고 표에 표시합니다.
- 10차시는 6·9차시 기록이 있으면 자동으로 가져옵니다. 개인 성찰은 한 기기에서 구성원 탭을 바꿔 가며 작성합니다. 시간이 부족하면 개인 성찰은 과제로 돌려도 됩니다.
